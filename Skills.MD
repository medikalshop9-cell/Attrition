# Skills Developed

## 1. Technical Skills
### Objective
- Build a machine learning system in R that predicts employee attrition and deploy it through a React-based interface for interactive use.
### Data Preparation & Exploration
- Cleaning and preprocessing structured HR datasets
- Performing Exploratory Data Analysis (EDA) to uncover patterns
- Identifying relationships between employee characteristics and attrition

### Statistical & Machine Learning Modeling
- Logistic Regression (baseline and interpretable modeling)
- Regularized models for controlling overfitting
- Decision Trees for capturing nonlinear relationships
- K-Means Clustering for employee segmentation

### Programming in R
- Writing structured and reproducible R scripts
- Data manipulation using dplyr
- Data visualization using ggplot2
- Model building and evaluation using caret and rpart

### Model Evaluation & Validation
- Applying train/test split and cross-validation
- Evaluating models using:
  - Confusion Matrix
  - Accuracy
  - Precision and Recall
  - F1-score and ROC-AUC
- Diagnosing bias vs variance issues
