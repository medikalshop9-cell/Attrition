# Predicting Employee Retention Using AI

## Overview
This project explores how artificial intelligence can help predict employee attrition and support proactive Human Capital Development strategies.

## Research Question
Which employee factors most strongly predict attrition, and how can AI help managers make better decisions?

## Dataset
- IBM HR Analytics Employee Attrition Dataset
- 1,470 employees
- 35 variables including:
  - Demographics
  - Job characteristics
  - Satisfaction scores
  - Compensation

## Methodology

### 1. Exploratory Data Analysis
- Attrition by age, department, income
- Visualization using ggplot2

### 2. Logistic Regression
- Identify key predictors
- Interpret coefficients

### 3. Decision Tree
- Generate decision rules
- Evaluate model accuracy

### 4. K-Means Clustering
- Segment employees into risk groups
- Identify high-risk profiles
